# Релиз v3.2.0: Комплексное оформление GitHub, двуязычный README (RU/EN) и подробные инструкции

## Дата релиза: 18 ноября 2026 г.

### 1. Цель релиза
Приведение презентационной и технической документации репозитория на GitHub к высочайшему индустриальному стандарту:
* Разработка полноценного двуязычного `README.md` (Русский и Английский языки) с быстрой навигацией по якорям.
* Интеграция бейджей статуса проекта (Версия v3.2.0, 79/79 пройденных тестов, платформа Windows, лицензия MIT, Zero Data Loss, двунаправленность).
* Детальные иллюстрированные руководства для конечных пользователей:
  * Пошаговая инструкция по переносу **Android ➔ iPhone** (включая работу с No-Root ассистентом Viber Desktop и архивами Google Drive).
  * Пошаговая инструкция по реверс-миграции **iPhone ➔ Android** (включая упаковку `viber_backup.zip` с проверкой CRC32).
  * Исчерпывающее руководство по физическому подключению iPhone к ПК (диалог «Доверять этому компьютеру», параметры резервного копирования в iTunes/Apple Devices без пароля, отключение «Локатора»).
* Архитектурная Mermaid-диаграмма преобразования потоков данных и описание всех 7 слоев системы.
* Таблица тестовой матрицы со 100% прохождением всех 20 тестовых сьютов.
