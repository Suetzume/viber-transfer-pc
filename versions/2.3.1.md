## Исправления и улучшения

### 1. Автоматическое освобождение порта при EADDRINUSE
* **Проблема:** Если предыдущий процесс сервера или тестов не успел закрыться или был запущен в фоне, повторный запуск `Start_App.bat` вызывал необработанное исключение `Error: listen EADDRINUSE: address already in use :::34567`.
* **Решение:** В модуль `src/server/bridge-server.js` добавлена функция `freePortIfBusy(port)` и обработчик ошибки `onError`. Если порт `34567` занят зависшим старым процессом, сервер автоматически определяет его PID, принудительно освобождает порт и корректно перезапускается без падений.

### 2. Исправление кодировки UTF-8 в Windows CMD (.bat файлы)
* **Проблема:** При запуске `.bat` файлов в стандартной командной строке Windows текст заголовков и баннеров отображался «кракозябрами» (`щя=Aщ...`) из-за кодовой страницы по умолчанию cp866.
* **Решение:** Во все командные файлы (`Start_App.bat`, `Run_Tests.bat`, `Run_Benchmark.bat`, `Run_CLI_Demo.bat`) добавлена директива `@chcp 65001 > nul`, включающая кодировку UTF-8.
