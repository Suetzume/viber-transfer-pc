# Релиз v3.3.2: Явная индикация обязательного требования Root-доступа для прямого USB/ADB-метода и проверка статуса Root в реальном времени

## Дата релиза: 21 ноября 2026 г.

### 1. Исправленные проблемы и улучшения
1. **Явное указание обязательного требования Root-доступа на вкладке USB/ADB (`#usbRootRequirementBanner`):**
   * **Причина:** При выборе первой вкладки («USB Смартфон») не было явно выделено предупреждение о том, что для прямого извлечения текстовой базы чатов (`/data/data/com.viber.voip/databases/viber_messages`) по кабелю USB через ADB **обязательно требуется наличие Root-доступа (`su`)** на смартфоне.
   * **Решение:**
     * Вкладка переименована в **«📱 USB Смартфон (Root / ADB)»** (`📱 USB Smartphone (Root / ADB)`).
     * Под карточкой подключенного телефона добавлен заметный информационный блок предупреждения (`#usbRootRequirementBanner` на русском и английском языках), четко разъясняющий:
       * Почему для прямого чтения `/data/data/com.viber.voip/databases/viber_messages` по кабелю обязателен Root-доступ (`su`).
       * Что на обычных (нерутированных) телефонах система Android блокирует раздел `/data/data/` (по ADB доступны только медиафайлы), поэтому без Root необходимо использовать способы **«Viber Desktop (ПК)»** или **«Архив Google Drive»**.
2. **Аппаратная проверка наличия Root-прав (`su -c id`) в `adb-connector.js`:**
   * При подключении смартфона по USB автоматически проверяется наличие прав суперпользователя (`dev.hasRoot`).
   * Если Root присутствует (`uid=0`), база `/data/data/com.viber.voip/databases/viber_messages` автоматически копируется во временный буфер и выгружается по ADB.
   * Если Root отсутствует (`dev.hasRoot === false`), в карточке устройства и в баннере требования в реальном времени отображается статус:
     `🔒 Статус вашего телефона (Xiaomi 13 Ultra): Root-доступ НЕ обнаружен. Прямое чтение текстовой базы по USB заблокировано защитой Android 16 — выберите «Viber Desktop (ПК)» или «Архив Google Drive» ниже.`

### 2. Модифицированные файлы
* `src/devices/android/adb-connector.js` — проверка `su -c id` (`dev.hasRoot`) и автоматическое извлечение базы при наличии Root.
* `src/renderer/index.html` — переименование вкладки в `📱 USB Смартфон (Root / ADB)`, добавление двуязычного баннера `#usbRootRequirementBanner` и динамического индикатора `#usbRootLiveStatus`.

* `package.json`, `README.md`, `versions/3.3.2.md` — обновление версии до `v3.3.2`.
