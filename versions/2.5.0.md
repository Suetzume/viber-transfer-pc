## Реализованные улучшения (Этап 4: Пакетный перенос медиавложений)

### 1. Архитектура контентно-адресуемого хранилища (Media CAS)
* **Модуль `media-pipeline.js`:** Реализован специализированный конвейер поиска, валидации и физической инжекции медиафайлов (фотографии, видеозаписи, голосовые сообщения PTT, стикеры, документы).
* **Контроль побайтовой целостности (Bitwise Fidelity):** Для каждого переносимого бинарного файла вычисляется криптографический хеш SHA-256 (`computeContentHash`). Это исключает повреждение или неполную запись вложений при миграции.

### 2. Физическая инжекция медиавложений в резервную копию iTunes
* **Схема адресации Apple MobileSync:**
  - Каждый медиафайл привязывается к App Group домену iOS Viber: `AppDomainGroup-group.viber`.
  - Относительный путь нормализуется в канонический формат: `Attachments/<filename>`.
  - Рассчитывается 40-значный SHA-1 `fileID`: `SHA-1('AppDomainGroup-group.viber-Attachments/' + filename)`.
  - Файл физически записывается по двухсимвольному субкаталогу: `<backupDir>/<fileID[0..2]>/<fileID>`.
* **Регистрация в `Manifest.db`:**
  - Генерируется бинарный plist-дескриптор `bplist00` с точным размером файла в байтах, таймстампами и POSIX-атрибутами (права доступа `Mode: 33188` / `0o100644`).
  - Выполняется транзакционный `upsert` в таблицу `Files` базы `Manifest.db`.
* **Связка с CoreData `Chat.data`:**
  - Поле `ZATTACHMENTPATH` в таблице `ZMESSAGE` указывает на `Attachments/<filename>`.
  - Поле `ZMEDIAFILESIZE` заполняется точным размером файла.

### 3. Реверс-миграция медиафайлов (iPhone ➔ Android)
* Модуль `extractMediaFromIOSBackup` выполняет обратное извлечение всех вложений из резервной копии iTunes по их хешированным идентификаторам и упаковывает их в официальный zip-архив Google Drive (`viber_backup.zip`) в подпапку `media/<filename>`.

### 4. Обновление GUI и интерфейса
* В интерфейс (`index.html`) добавлена отдельная плашка статистики **«Вложений (Медиа)»** (`statMedia`).
* Финальный отчет миграции отображает количество диалогов, сообщений и перенесенных медиавложений.
* Обновлен бейдж версии: `v2.5.0 • Stage 4 Media CAS`.

### 5. Автоматизированное тестирование
* Добавлен новый сьют тестов `tests/stage4-media-transfer.test.js` (5 тестов):
  - Нормализация путей и имен медиафайлов (Windows/POSIX).
  - Детерминированное вычисление SHA-256 CAS хеша.
  - Физическая инжекция файлов в структуру бэкапа и регистрация в `Manifest.db`.
  - Сквозная миграция из архива Google Drive (`viber_backup.zip`) с медиавложениями в iTunes бэкап.
  - Реверс-миграция из iTunes бэкапа с медиавложениями в архив `viber_backup.zip`.
* Устранены блокировки файлов SQLite на Windows через `finally { if (isOwnedDb) db.close(); }` в адаптерах.
