## 1. Обзор релиза v2.1.0

Версия `v2.1.0` завершает подготовку настольной версии приложения для ПК (Windows Desktop Edition) по двум ключевым направлениям:
1. **Экстремальное нагрузочное стресс-тестирование (50 000+ сообщений):** подтверждена высочайшая производительность ядра, отсутствие утечек памяти и 100% сохранение целостности (Zero Data Loss).
2. **Автономный дистрибутив `ViberTransfer.exe`:** приложение собрано в единый портативный исполняемый файл Windows PE, который запускается в один клик без необходимости установки Node.js или каких-либо внешних библиотек.

## 3. Автономный исполняемый файл `ViberTransfer.exe`

С помощью встроенного в современный Node.js механизма **Single Executable Applications (Node SEA)** и скрипта `scripts/build-standalone.js` собран единый бинарный файл `ViberTransfer.exe`:
- **Полная автономность:** все DDL-схемы баз данных SQLite и веб-интерфейс `index.html` виртуально внедрены внутрь бинарного файла.
- **Размещение:** `ViberTransfer.exe` размещен в корневой папке проекта для запуска пользователем в один клик.
- **Автоматический запуск:** при двойном клике запускается встроенный BridgeServer и автоматически открывается окно веб-интерфейса в браузере по адресу `http://localhost:34567`.

## 4. Новые утилиты и тесты

- `ViberTransfer.exe` — портативный исполняемый файл Windows.
- `Run_Benchmark.bat` — пакетный запуск стресс-теста на 50 000 сообщений в один клик.
- `scripts/run-benchmark.js` — модуль бенчмаркинга и генерации тестовых наборов.
- `scripts/build-standalone.js` — сборочный конвейер Node SEA.
- `tests/stress-benchmark.test.js` — автоматический тест пропускной способности (>10 000 msgs/sec).
- `tests/standalone-exe.test.js` — интеграционный тест запуска и работоспособности `ViberTransfer.exe`.
