## Реализованные улучшения (Этап 7: Переключатель языков и защита от зомби-процессов)

### 1. Переключатель языков интерфейса (🌐 RU <-> EN Switcher)
* **Кнопка переключения в шапке:** Добавлена стилизованная кнопка `#langSwitchBtn` с динамическим индикатором `#currentLangLabel` (`RU` / `EN`).
* **Полноценная двуязычная локализация (i18n):**
  - Создан полный словарь `I18N` (`ru` и `en`), покрывающий 100% элементов интерфейса: шапка, бренд, степпер (Шаг 1, 2, 3), кнопки выбора файлов, карточки ассистента Viber Desktop, инструкции по архивам Google Drive, предупреждения демо-режима, блоки Apple iTunes MobileSync, блок валидации шифрования, итоговая карточка сводки, метрики прогресса (Диалогов, Сообщений, Вложений, Дубликатов, Времени), финальный пошаговый мастер восстановления на iPhone и Android.
  - Сохранение выбранного языка в `localStorage.getItem('viber_transfer_lang')` — язык сохраняется между перезапусками приложения и обновлением страницы.
  - Функция `toggleLanguage()` плавно переключает активный язык на лету без перезагрузки страницы.

### 2. Защита от конфликта портов EADDRINUSE и Mojibake в консоли Windows
* **Автоматическое освобождение порта 34567:** В `Start_App.bat` встроен механизм поиска и мягкого завершения повисших фоновых процессов-зомби на порту 34567 перед стартом нового сервера.
* **Исправление кодировки Windows CMD:** Файлы пакетных скриптов (`Start_App.bat`, `Open_UI.bat`) стандартизированы с кодировкой UTF-8 без BOM и явным переключением `chcp 65001 >nul` для предотвращения кракозябр (`ЩяТАщ...`).
* **Отключение кеширования в браузере (Cache-Control):** В `bridge-server.js` эндпоинты статики снабжены заголовками `Cache-Control: no-cache, no-store, must-revalidate`, исключающими показ устаревших версий интерфейса в Google Chrome.

### 3. Автоматизированное тестирование
* Добавлен новый сьют тестов `tests/stage7-i18n.test.js` (4 теста):
  - Контракт UI: проверка наличия `#langSwitchBtn`, `#currentLangLabel`, `toggleLanguage()`, стилей `.lang-switch-btn`.
  - Контракт I18N: валидация словаря `I18N` — проверка совпадения количества ключей в `ru` и `en`, отсутствия пустых строк.
  - Контракт элементов DOM: наличие всех необходимых ID для динамического перевода.
  - Сетевой контракт: проверка заголовков `Cache-Control: no-cache` и версии `v3.1.0`.

### 4. Автономный исполняемый файл ViberTransfer.exe
* Пересобран бинарный файл `ViberTransfer.exe` (95.82 MB) с актуальным двуязычным веб-интерфейсом.
