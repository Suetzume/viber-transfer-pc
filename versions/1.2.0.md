# Версия 1.2.0 (Слой 6: Интеграция графического интерфейса Desktop UI с ядром через BridgeServer)

* **Дата релиза:** 16.11.2026
* **Тип изменения:** Разработка локального API-моста (`BridgeServer`), связывание веб-интерфейса мастера переноса (`src/renderer/index.html`) со сквозным ядром миграции (`MigrationEngine`), реализация Server-Sent Events (SSE) для стриминга прогресса в реальном времени и создание исполняемого ярлыка `Start_App.bat`.

---

### Состав изменений:
1. **Локальный API-мост (`src/server/bridge-server.js`):**
   * Работает на встроенном модуле `node:http` без сторонних зависимостей.
   * `GET /api/detect-desktop`: возвращает обнаруженные локальные базы Viber Desktop с путями и размерами.
   * `GET /api/preflight`: проверяет объем оперативной памяти, архитектуру ОС и флаги готовности.
   * `POST /api/migrate`: запускает реальный пайплайн миграции SQLite на бэкенде.
   * `GET /api/events`: SSE-стрим для пошаговой трансляции прогресса миграции прямо в браузер.
2. **Интерактивный графический интерфейс (`src/renderer/index.html`):**
   * Автоматически определяет статус сервера при загрузке: отображает зеленый бейдж `Бридж-сервер: В сети (Online)`.
   * Выводит реальный объем доступной памяти ПК в панели предварительной проверки.
   * Автоматически подставляет путь и размер найденной локальной базы Viber Desktop.
   * При клике на кнопку переноса отправляет команду на бэкенд и плавно анимирует прогресс-бар, счетчики сообщений и консольный лог.
3. **Ярлык запуска приложения на Рабочем столе:**

4. **Автоматические тесты слоя (`tests/bridge-server.test.js`):**
