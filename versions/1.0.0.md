# Версия 1.0.0 (Архитектурный фундамент и генеральный план)

* **Дата релиза:** 16.11.2026
* **Тип изменения:** Инициализация проекта, формулирование генерального архитектурного плана, регламента версионирования и базовой структуры репозитория.

---

### Состав изменений:
1. **Инициализация Git-репозитория:**
   - Создана базовая структура директорий (`src/`, `versions/`, `tests/`, `docs/`).
   - Настроен локальный `.gitignore` для защиты от попадания кэшей, персональных баз данных и бинарных дампов.
2. **Разработка технического плана (Master Plan):**
   - Исследована разница хранения данных Viber между Android (Google Drive / SQLite `viber_data`) и iOS (iTunes Backup / `Manifest.db` / `Chat.data` / `Contacts.data`).
   - Заложена математическая модель конвертации времени (Unix Epoch 1970 vs Apple Cocoa Epoch 2001, дельта 978,307,200 секунд).
   - Спроектирована архитектура канонического промежуточного слоя **Unified Intermediate Model (UIM)**.
   - Определена стратегия безопасного переноса без повреждения системных файлов устройств (Zero Data Loss).
3. **Регламент версионирования:**
   - Установлено правило: каждое последующее изменение сохраняется отдельным файлом `versions/<версия>.md`.
   - Задана логика шагов: `1.0.x` (модули и патчи ядра) -> `1.1.0` (первый сквозной рабочий движок) -> `1.2.0` (бета с UI) -> `2.0.0` (глобальный релиз).
