# Версия 1.0.3 (Финальный эталонный архитектурный план и матрица TDD)

* **Дата релиза:** 16.11.2026
* **Тип изменения:** Финализация архитектурного плана системы, утверждение 6-слойной слабосвязанной архитектуры («Black-Box Isolation»), спецификация отказоустойчивости (FMEA) и детальный пошаговый план разработки с автоматическим тестированием каждого этапа.

---

### Состав изменений:
1. **Утвержден окончательный мастер-план (1.0.3-FINAL-PLAN):**
   * Специфицированы схемы хранения данных Android (`viber_messages.db`) и iOS (`Chat.data` / `Contacts.data`).
   * Зафиксированы проверенные открытые репозитории с GitHub (`mbv06/ViberDBViewer`, `iPhone-Backup-Analyzer-2`, `watoi`, `WaBridge`).
   * Закреплена матрица отказоустойчивости для обхода реальных блокировок мобильных ОС (Viber Desktop локальная SQLite база, пре-валидация «Локатора» iOS, побайтовый расчет `Manifest.db`, сдвиг ключей `KeyRebalancer`, CAS-хранилище медиа).
2. **6-слойная модульная архитектура:**
   * Слой 1: Фундамент (Time & Hash Engine).
   * Слой 2: Каноническая UIM-модель и валидатор.
   * Слой 3: Адаптеры баз данных SQLite (Android & iOS).
   * Слой 4: Слой инъекции бэкапа и манифестов.
   * Слой 5: Оркестратор миграции и проверка целостности.
   * Слой 6: Аппаратные драйверы и Desktop UI Wizard.
3. **План перехода к практической кодогенерации:**
   * Следующий шаг (1.0.4) — реализация модулей Слой 1 (`TimeEngine`, `HashService`) и Слой 2 (`UIM Contracts & Validator`) со 100% покрытием автоматическими тестами через `node:test`.
