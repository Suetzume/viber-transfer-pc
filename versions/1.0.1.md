# Версия 1.0.1 (Интеграция открытых баз данных и схем с GitHub)

* **Дата релиза:** 16.11.2026
* **Тип изменения:** Дополнение архитектурного плана интеграцией проверенных репозиториев, референсных DDL-схем баз данных SQLite и открытых инструментов цифровой криминалистики с GitHub.

---

### Состав изменений:
1. **Анализ и интеграция открытых проектов с GitHub:**
   * `mbv06/ViberDBViewer` — спецификация схемы `viber_messages.db` и `viber.db` для Android.
   * `staniond/Viber_message_extractor` и `ptmorris03/ViberExtractor` — алгоритмы выборки сообщений и тредов.
   * `VertexAI/iPhone-Backup-Analyzer-2` (`plg_viber.py`) — спецификация структуры `Chat.data` и `Contacts.data` для iOS.
   * `conorarmstrong/iphone_extract_backup` и `datatags/mount-ios-backup` — парсинг и пересчет хешей `Manifest.db`.
   * `residentsummer/watoi` и `Parv3sh/WaBridge` — референсная архитектура бесконфликтной инъекции данных в iOS Backup без сброса устройства.
2. **Создание каталога эталонных фикстур (`fixtures/schemas/`):**
   * Добавлен `fixtures/schemas/android_viber_messages.sql`.
   * Добавлен `fixtures/schemas/ios_viber_chat.sql`.
   * Добавлен `fixtures/schemas/sample_manifest.sql`.
   * Теперь конвертер сможет тестироваться автономно на реальных структурах без необходимости постоянного подключения телефонов.
3. **Обновление Генерального плана (Master Plan):**
   * Раздел 2 полностью посвящен интеграции данных из GitHub-репозиториев.
   * Версия плана повышена до `1.0.1-PLAN`.
