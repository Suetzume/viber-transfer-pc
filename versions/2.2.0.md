## Реализованные улучшения (Этап 1: Честная аппаратная диагностика)

### 1. Встроенный переносной ADB (Portable Android Debug Bridge)
* Добавлен переносной бинарный пакет `bin/platform-tools/` (`adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll`).
* Приложение больше не требует от пользователя ручной установки Android Studio или настройки переменной `PATH`. Поиск исполняемого файла теперь происходит автономно и мгновенно.

### 2. Реальное определение физических устройств Android
* **Распознавание реального смартфона пользователя:** система сразу определила подключенный по USB смартфон:
  - **Модель:** `XIAOMI 2304FPN6DG` (Xiaomi 13 Ultra, codename `ishtar`).
  - **Версия Android:** `16`.
  - **Статус отладки:** `device` (авторизован и готов к чтению).
  - **Статус Viber:** `com.viber.voip` обнаружен и проверен.
* **Windows PnP Fallback:** если режим «Отладка по USB» на телефоне выключен, система через Windows PnP определяет факт подключения смартфона по кабелю и выводит целевую инструкцию по активации меню разработчика.

### 3. Честная диагностика и сценарий для iPhone
* **Определение служб Apple:** проверка наличия классического `iTunes` (`iTunes.exe`) и UWP-приложения `Устройства Apple` (`AppleDevices.exe`).
* **Пошаговое руководство для iPhone:**
  1. Если iTunes не установлен — вывод сообщения и ссылки на загрузку из Microsoft Store / Apple.
  2. Если бэкап отсутствует — вывод 4 шагов создания незашифрованной локальной копии в iTunes.
  3. Если бэкап найден — проверка `Manifest.db`, отсутствия пароля и готовности к инъекции.
